# Riot Accounts

Windows 11・x64向けの個人用Riotアカウント管理アプリ。アカウント切り替えのログイン補助と、LoLのランク・戦績確認に対応します。

## 起動・初期設定

配布ZIPは、後述の `scripts/publish.ps1` で作成できます。

1. `RiotAccounts-win-x64.zip` をフォルダごと展開し、`RiotAccounts.exe` を起動します。.NETランタイムは同梱しています。
2. 「アカウントを追加」で管理名、ログインID、パスワード、Riot IDの名前とタグ、サーバーを登録します。ログインIDとゲーム内のRiot IDは別項目です。初期サーバーはJP1です。任意でメモ（用途など）も残せます。メモは詳細画面に表示し、検索の対象にも含めます。
3. 「設定」→「自動入力を設定する」を開き、クライアントの確認 → ログイン画面の準備 → 入力欄の確認の順に進めます。通常はインストール情報からクライアントを検出します。見つからない場合は `RiotClientServices.exe` を選びます。「次へ」で場所を保存します。
4. LoLの情報を取得する場合は [Riot Developer Portal](https://developer.riotgames.com/) で取得したAPIキーを設定します。開発用キーは24時間で失効します。キーをソースコードや配布ファイルに書き込む必要はありません。キーを使わずに非公式の OP.GG から取得することもできます（「取得元」を参照）。

## アカウント一覧

一覧の各行に、保存済みの最新ランク（Solo/Duo、なければFlex）と最終プレイ日（「今日」「3日前」など）を表示します。一覧の表示では通信しません。ランクは最後に更新した時点の観測値、最終プレイ日は取得済みの試合のうち最新のものです。未取得の場合は「ランク未取得」「試合未取得」と表示します。

## アカウントの並べ替え

一覧の各行にある三本線を上下へドラッグすると、アカウントの順番を変更できます。順番は保存され、再起動や情報更新の後も維持されます。検索中・処理中は並べ替えを無効にしています。検索欄を空にし、処理が完了してから操作してください。

手動で並べ替えるまでは管理名順です。並べ替え後に追加したアカウントは末尾へ入り、名称を編集しても順番は変わりません。

キーボードでは、三本線にフォーカスして `Alt+↑` / `Alt+↓` で1つずつ移動できます。ドラッグ中は `Esc` または一覧外へのドロップでキャンセルできます。

## ログイン

Riotクライアントで別アカウントからログアウトしてから、「Riotにログイン」を押します。クライアントを前面に表示し、入力欄を確認してID・パスワードを入力、ログインを送信します。送信後の認証結果と追加認証はRiotクライアントで確認してください。

現在のRiotクライアント（Electron製）は、入力欄をUI Automationで識別できません。そのため、入力欄の位置を登録し、画面の見た目（画素）で確認しながら入力します。

設定の案内では、Riotクライアントを開き、ログアウトしてID・パスワード欄を空にした後、「Riot画面を確認する」を押します。位置が未登録（または画面サイズ・表示倍率・クライアントのバージョンが変わった）場合は「位置登録を開始」を押し、ID欄（上）、パスワード欄（下）の順に、入力欄の中央にマウスを置いてF8を押してください。登録の最後に、アプリが各欄を1回ずつクリックして「空でフォーカスした状態」を記録します。案内に「1/2 ID欄」のように現在の手順を表示します。Escで中止でき、最初からやり直せます。中止・失敗では以前の登録を保持します。

登録後は「試験入力を確認する」で、ダミー文字が実際に入力欄へ入ることを確認します（入力後に消去し、ログイン送信はしません）。ログイン時と同じ入力経路を試せます。入力先を安全に確認できない場合は「個別コピーを使う」から手動入力の案内を確認できます。

「Riotにログイン」は、各欄が登録時の空の状態と一致し、文字が入ったことを画面で確認できた場合だけ、パスワード欄でEnterを押してログインを送信します（確認できない場合は送信せずに止まり、止まった段階を表示します）。失敗の段階と理由は `%LOCALAPPDATA%\RiotAccounts\logs\diagnostics.log` に記録されます。ログにID・パスワード・入力内容は含まれません。

入力中はマウス・キーボードを操作せず、Escで中止できます。ウィンドウや入力先が変わると入力を止めます。「IDをコピー」「パスワードをコピー」から手動でCtrl+Vすることもできます。パスワードのコピーは30秒後、またはアプリ終了時に消去します。その間に別の内容をコピーした場合は消去しません。

## ランク・戦績

- 「全ランク更新」：登録アカウントのSolo/Duo・Flexランク、LP、勝敗を取得します。
- 「戦績・分析更新」：選択中キューの直近20戦／50戦、KDA、CS/分、チャンピオン・ロール別成績を取得します。
- 「ノーマル」を選ぶと、ドラフト・ブラインド・スイフトプレイ・クイックプレイの履歴を日時順にまとめて表示します。「戦績更新」で取得し、各試合の種別も確認できます。ノーマルにはランク・LP推移・参考ランク帯を表示しません。
- 「試合履歴」：行をダブルクリック（またはEnter）すると、両チーム10人のチャンピオン・ロール・K/D/A・CS/分・視界スコアを表示します。自分の行を強調します。他のプレイヤーの名前は保存していないため表示しません。
- 「分析」の「全アカウントのチャンピオン別」：登録済みの全アカウントの保存済み戦績から、選択中のキューについて各アカウントの直近20戦／50戦をチャンピオン別に合計し、アカウント別の試合数も表示します。複数の自アカウントが同じ試合に出た場合は、アカウントごとに1戦と数えます。通信はしません。
- 「推移」：更新時点のランク・LPの観測記録です。昇降格を表示し、異なるランク間の線は接続しません。観測間の変化を1試合のLP増減とは扱いません。
- 「次戦の参考ランク帯」：同じキューの直近30日・最大20戦に登場した相手の**取得時点のランク**から中央値・25〜75%の範囲を計算します。10戦以上、相手ランク取得率80%以上が必要です。内部MMRや対戦当時のランクではなく、次戦の相手や勝率を保証するものではありません。

起動時は保存済みの情報を表示します。更新は手動です。API制限で待機中も「中止」が使えます。通信やキーの失効で取得できなくても、保存済みの情報は保持します。リメイクは成績集計から除外します。

### 取得元（Riot API / OP.GG）

「設定」→「ランク・戦績の取得元」で OP.GG を選ぶと、APIキーなしでランク・戦績を取得できます。既定は Riot API です。

- OP.GG の取得は**非公式**です（OP.GG が公開していない Web 用の通信を利用）。予告なく仕様変更・遮断されて使えなくなることがあり、OP.GG の利用規約上も個人利用の範囲にとどめてください。取得できない場合は Riot API に切り替えてください。
- OP.GG 側でデータが更新されていないと、最新の試合やランクが含まれません（このアプリから OP.GG の更新は要求しません）。
- 取得元に関係なく、詳細画面の「OP.GGで開く」で選択中アカウントの OP.GG ページを既定のブラウザで開けます。

### 取得できないとき（接続の診断）

画面上部の「接続を診断」で、選択中の取得元について 段階ごと（Riot API：APIキー → Riot ID解決 → ランク → 試合一覧 → 試合詳細／OP.GG：アカウント検索 → summary → games → チャンピオン情報）に成功・失敗・HTTPコード・所要時間を確認できます。診断は読み取りのみで、データは保存しません。APIキー・PUUID・応答の内容は表示もログ記録もしません。結果は「結果をコピー」で貼り付けられます。

更新のたびに、取得元・経路（IDは伏せた形）・HTTPコード・失敗の種類を `%LOCALAPPDATA%\RiotAccounts\logs\diagnostics.log` に記録します（サイズ上限つき）。取得に失敗した場合、取得元は自動では切り替えず、画面に診断と切り替えの案内を表示します。アカウント画面には現在の取得元と最終取得時刻を表示します。
- 「次戦の参考ランク帯」は Riot API 利用時のみ算出します。
- 取得元を切り替えても保存済みの戦績は保持し、同じ試合は Riot API のデータを優先して1件として集計します。

## 保存先

`%LOCALAPPDATA%\RiotAccounts\accounts.db` に保存します。ログイン情報・APIキーはWindows DPAPIで暗号化し、登録したWindowsユーザーで復号します。別のユーザーやPCにDBだけを移しても復号できません。試合・ランク情報、管理名、メモはローカルDBに通常データとして保存します（メモは暗号化しないため、ログイン情報を書かないでください）。

バックアップ時はアプリを閉じて保存先フォルダ全体をコピーしてください。アカウント削除で、そのアカウントのログイン情報と保存済み分析を削除します。

## 開発・検証

必要環境：.NET 10 SDK。Windows UIの動作検証はWindowsで行います。

```powershell
dotnet test tests/RiotAccounts.Core.Tests -c Release
dotnet build src/RiotAccounts.App -c Release
powershell -ExecutionPolicy Bypass -File scripts/publish.ps1
```

配布版のオフライン診断（ダミーの一時データのみ使用）：

```powershell
$p = Start-Process .\RiotAccounts.exe -ArgumentList '--self-test', 'smoke-results.txt' -Wait -PassThru
Get-Content .\smoke-results.txt
$p.ExitCode
```

実機検証の結果と未実施項目は `docs/windows-validation.md`、ログイン操作の確認手順は `docs/login-validation.md` を参照してください。実APIとの照合には本人の有効なAPIキーとアカウントが必要です。

# Windows 検証

## 自動検証

配布フォルダーで PowerShell から実行します。Riot クライアント、実アカウント、API 通信を使わず、一時フォルダーと生成したダミー値だけで検証します。

```powershell
$report = Join-Path $PWD "self-test-report.txt"
$test = Start-Process .\RiotAccounts.exe -ArgumentList @("--self-test", "`"$report`"") -Wait -PassThru
Get-Content $report
$test.ExitCode
```

終了コード `0` と各項目の `PASS` を確認します。失敗時は終了コード `1`、該当項目に `FAIL` と例外型が出ます。秘密情報はレポートに出しません。

レポートの保存先に、メイン画面の `self-test-empty.png`・`self-test-sample.png`・`self-test-normal.png`・`self-test-normal-matches.png`・`self-test-reorder.png`（1220 × 850）、空の追加画面 `self-test-account-add.png`、設定画面 `self-test-settings.png` も出力します。空状態と架空の保存済みアカウントを描画したものです。ユーザーのデスクトップや実データを撮影せず、画面レイアウトを確認できます。

- Windows DPAPI CurrentUser で暗号化・復号でき、改変データの復号が拒否される。
- SQLite に保存したアカウント・認証情報・API キー・キャッシュを再接続後も読める。
- 管理名のみの編集で認証情報を維持し、認証情報の変更を保存できる。
- SQLite 本体・WAL を含む関連ファイルに、ダミーのログイン ID・パスワード・API キーが UTF-8 / UTF-16 の平文で含まれない。
- アカウント削除で認証情報とキャッシュも削除され、共通 API キーは維持される。
- メイン画面・追加/編集ダイアログ・設定画面を、空データとダミーの保存済みデータで構築できる。表示・フォーカス・入力操作は行わない。
- ノーマル4種を混在させたダミー履歴から、4戦・2勝・2敗とチャンピオン別・ロール別の成績が表示され、同じキャッシュ内のSolo/Duo・Flex・ARAMが混入しない。試合履歴には各試合のモード名が表示される。
- ノーマルではランク・LP推移を隠してランクの表示値を消去し、次戦の参考ランク帯は「相手のSolo/Duoランク基準」の見出しでノーマル用の予測（レベル推定の件数つき）を表示する。推移タブを開いてノーマルへ切り替えると概要タブへ移り、Solo/Duo・Flexへ戻すと各キューのランク・履歴・予測が再表示される。
- アカウントの並び替えで選択とデータを維持し、保存後の読み直しでも順序を維持する。検索中・処理中は順序変更を受け付けない。三本線の描画幅、ドラッグ開始距離、ドロップ先の上下判定と一覧外の拒否も検証する。
- Windows の INPUT 構造体サイズと、合成画像を使った入力欄画像の一致・変更・サイズ不一致を検証する。画面キャプチャやキーボード入力は行わない。
- 位置登録のウィンドウサイズ・DPI・クライアント版・保存形式・入力欄範囲が不一致の場合に、再利用が拒否されることを検証する。
- 検証終了後に一時データを削除できる。

## 対話デスクトップで確認する項目

SSH からのオフライン検証だけでは、実際の画面への入力やフォーカス操作は検証できません。以下は本人の Windows デスクトップ上で確認します。

1. アカウントの追加・編集・検索・削除、アプリ再起動後の表示を確認する。三本線からのドラッグで先頭・中央・末尾へ移動し、挿入位置表示、端のスクロール、Esc・一覧外キャンセル、Alt+↑／↓、検索中・処理中の禁止も確認する。
2. テキストをコピーしてからパスワードをコピーし、変更しない場合は約30秒で消去されることを確認する。30秒以内に別の内容をコピーした場合は、その内容が残ることも確認する。
3. Riot の空のログイン画面で入力欄の自動検出を確認する。自動試験にはダミー情報を使い、実アカウントでの送信・追加認証は本人が行う。
4. 自動検出できない画面で入力位置を登録する。ウィンドウを移動しても座標が追従し、サイズ・DPI・クライアント版・画面構成が変わった場合は再登録を求めることを確認する。
5. 入力開始前・入力途中にフォーカスを別ウィンドウへ移し、入力が中止されることを確認する。Esc による中止も確認する。
6. 送信後の表示が「認証成功」を断定せず、クライアントの結果確認を案内することを確認する。
7. 本人が設定した API キーで Solo/Duo と Flex のランク・直近戦績を照合する。ノーマルではQuickplay・Swiftplay・Draft Pick・Blind Pickの試合が取得対象になり、ランク戦・ARAMは表示されないことを照合する。サーバーで提供されないモードの履歴がなくても他の対象試合を取得でき、直近20戦・50戦が対象4種を合わせた件数になることを確認する。失効・通信失敗・キャンセルで保存済みデータが消えないことも確認する。

オフライン検証の成功は、実 Riot クライアントの自動操作や実 API の照合が完了したことを意味しません。
